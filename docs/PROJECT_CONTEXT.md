# ARQNOVA

Plataforma CASE colaborativa inteligente para modelado UML y generación automática de software.

- Frontend: React + Vite + TypeScript + Tailwind CSS + React Flow.
- Backend: NestJS + TypeScript + Prisma + Socket.IO.
- Base de datos: PostgreSQL.
- Autenticación futura: JWT y bcrypt para hashes de contraseña.
- Infraestructura: Docker y Docker Compose.

NestJS es el backend propio de ARQNOVA. Spring Boot será únicamente el backend generado por ARQNOVA.

El alcance actual es exclusivamente Fase 0. Los casos de uso de autenticación, proyectos, editor, colaboración UML, IA, XMI, generación y móvil no están implementados.
